# tust-immersed-tunnel-fire-risk

This repository contains the code, curated datasets, and simulation inputs associated with the paper:

**A reproducible hybrid framework for fire-risk inference in immersed tunnels using CFD-derived virtual sensors**

## Repository structure

- `paper/`: manuscript source files and figure assets
- `data/curated/`: processed datasets used in the analyses
- `fds/inputs/`: FDS input files used in the simulated scenarios
- `src/`: preprocessing, inference, and visualization scripts
- `docs/`: notes on reproducibility and workflow

## Scope

This repository was prepared specifically to support the reproducibility of the journal paper and does not include the full set of materials related to the broader dissertation project.

## Reproducibility

The workflow follows four main stages:

1. fire scenario simulation in FDS  
2. extraction of virtual sensor outputs  
3. preprocessing and dataset construction  
4. hybrid risk inference using fuzzy logic and machine learning
